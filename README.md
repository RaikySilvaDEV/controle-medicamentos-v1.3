# Controle de Medicamentos — v1.3

Nova versão mobile-first do Controle de Medicamentos.

## Direção visual

A autenticação será desenvolvida com foco em dispositivos móveis, usando como referência o modelo visual fornecido: fundo azul abstrato, cartão branco arredondado, formulário limpo, login com Google, recuperação de senha e cadastro no mesmo estilo.
